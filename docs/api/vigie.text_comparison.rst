Comparaison texte
=================

Sous-package du pipeline texte canonique (``vigie.analyse_texte.text_comparison``).
Serialise ``text_comparison.json``, produit l'export Excel analyste et porte les
helpers de justification utilises pour rendre lisibles les sorties du triage AMF.
