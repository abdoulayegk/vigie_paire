Composants de l’interface

Modules

interface.components.pdf_preview

UI only: affichage base64 Dash. Rendu pages PDF dans vigie.extraction.pdf_preview.

pdf_images_from_base64(images, captions=None)

Affiche des images PDF encodees en base64 dans une grille verticale.

Paramètres:

  • images (list[str]) – Liste de chaines base64 representant des images PNG.

  • captions (list[str] | None) – Legendes optionnelles pour chaque image. Si absent, des legendes Page 1, Page 2, … sont generees.

Type renvoyé:

Div

Renvoie:

Un Div contenant les images avec leurs legendes, ou un message de repli si images est vide.

interface.components.review_detail_v2

Composant de detail de revue V2 – interface de validation par changement.

Ce composant genere le panneau droit de l’interface de revue et affiche : - Les images de preuve (T1 et T2) - La liste des changements pour le tableau courant - Les boutons de validation par changement - Les controles de navigation

build_change_list_v2(changes, current_change_idx, *, current_quarter_label=None, previous_quarter_label=None)

Construit la liste des changements pour un tableau.

Paramètres:

  • changes (list[dict]) – Liste de dictionnaires ChangeItem.

  • current_change_idx (int) – Index du changement actuellement selectionne.

  • current_quarter_label (str | None) – Libelle du trimestre courant, si disponible.

  • previous_quarter_label (str | None) – Libelle du trimestre precedent, si disponible.

Type renvoyé:

ListGroup

Renvoie:

Un Div contenant la liste des changements.

build_review_detail_v2(table, current_change_idx, proof_image_t1_b64='', proof_image_t2_b64='', show_proofs=True, current_quarter_label=None, previous_quarter_label=None)

Construit le panneau complet de detail de revue V2.

Paramètres:

  • table (dict | None) – Dictionnaire ReviewTableItem courant.

  • current_change_idx (int) – Index du changement courant.

  • proof_image_t1_b64 (str) – Image de preuve T1 encodee en base64.

  • proof_image_t2_b64 (str) – Image de preuve T2 encodee en base64.

  • show_proofs (bool) – Si True, affiche la section des preuves visuelles.

  • current_quarter_label (str | None) – Libelle du trimestre courant, si disponible.

  • previous_quarter_label (str | None) – Libelle du trimestre precedent, si disponible.

Type renvoyé:

Div

Renvoie:

Le panneau de detail de revue complet.

build_validation_panel_v2(table, current_change_idx)

Construit les boutons de validation et le champ de notes pour le changement courant.

Paramètres:

  • table (dict) – Dictionnaire ReviewTableItem courant.

  • current_change_idx (int) – Index du changement courant dans le tableau.

Type renvoyé:

Div

Renvoie:

Un Div contenant les controles de validation.

interface.components.review_display_shared

Fonctions d’affichage partagees pour l’interface de revue Dash V2.

build_proofs_section(item, img_t1_b64, img_t2_b64, proof_display_mode='crop', proof_result_t1=None, proof_result_t2=None, current_quarter_label=None, previous_quarter_label=None)

Construit le panneau de preuves visuelles partage par la vue de detail V2.

Paramètres:

  • item (dict) – Dictionnaire du changement contenant les metadonnees du tableau.

  • img_t1_b64 (str | None) – Image base64 de la preuve T1 (trimestre precedent).

  • img_t2_b64 (str | None) – Image base64 de la preuve T2 (trimestre courant).

  • proof_display_mode (str) – Mode d’affichage ("crop", "full", "footnote" ou "full_without_bbox").

  • proof_result_t1 (dict | None) – Resultat de rendu pour la preuve T1.

  • proof_result_t2 (dict | None) – Resultat de rendu pour la preuve T2.

  • current_quarter_label (str | None) – Libelle du trimestre courant, si disponible.

  • previous_quarter_label (str | None) – Libelle du trimestre precedent, si disponible.

Type renvoyé:

Div

Renvoie:

Un Div contenant les cartes de preuve T1/T2 et le selecteur de mode.

compute_flag_state(item, *, current_quarter_label=None, previous_quarter_label=None)

Calcule les indicateurs visuels des cartes de preuve a partir du payload de changement.

Paramètres:

  • item (dict) – Dictionnaire du changement contenant change_type, added_indicators, removed_indicators et indicators.

  • current_quarter_label (str | None) – Libelle du trimestre courant, si disponible.

  • previous_quarter_label (str | None) – Libelle du trimestre precedent, si disponible.

Type renvoyé:

dict

Renvoie:

Dictionnaire avec les classes CSS et libelles de badges pour T1/T2.

section_display_label(section)

Convertit un identifiant de section en libelle lisible pour l’affichage.

Paramètres:

section (str | None) – Identifiant brut de la section (peut etre None).

Type renvoyé:

str

Renvoie:

Libelle francise de la section, ou "Autre section" par defaut.

table_display_label(item)

Formate un libelle de tableau de type rapport pour l’affichage.

Paramètres:

item (dict) – Dictionnaire contenant les metadonnees du tableau (table_name, table_number, page_t1/page_t2, section, change_type).

Type renvoyé:

str

Renvoie:

Libelle formate du tableau.

interface.components.review_queue_v2

Composant de file de revue V2 – tableaux groupes et dedupliques.

Ce composant genere le panneau gauche de l’interface de revue, affichant un element par tableau (et non par changement) avec indicateurs de progression.

build_review_queue_v2(tables, current_review_id, current_change_id=None, active_filters=None)

Construit le panneau de file de revue V2 avec tableaux groupes.

Paramètres:

  • tables (list[dict]) – Liste de dictionnaires ReviewTableItem (provenant de store-review-queue).

  • current_review_id (str | None) – Identifiant du tableau actuellement selectionne.

  • current_change_id (str | None) – Identifiant du changement actuellement selectionne.

  • active_filters (dict | None) – Filtres optionnels (section, statut).

Type renvoyé:

Div

Renvoie:

Un Div contenant le panneau complet de la file de revue.
