vigilance.models.comparison_models module

Modeles Pydantic pour le pipeline de comparaison GPT (Structured Outputs).

Ces modeles definissent les schemas de reponse stricts utilises par : - la revue Devil’s Advocate - le diff d’indicateurs - le diff de notes de bas de page - le filtre d’artefacts de l’inspecteur - la verification visuelle (Visual Sanity Check)

Ils remplacent l’ancien pattern de parsing dict[str, Any] libre par des sorties garanties typees via OpenAI Structured Outputs.
