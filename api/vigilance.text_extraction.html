Extraction texte

Sous-package du pipeline texte canonique. Écrit le markdown auditable (text_extraction_{q}.md), source de vérité narrative et entrée directe de la comparaison GPT, ainsi que l’audit bloc-à-bloc associé.

Modules

text_extraction.text_extraction_audit_writer

Lecture et écriture des artefacts d’audit d’extraction texte.

get_text_extraction_audit_path(out_dir, quarter_label)

Retourne le chemin canonique d’un artefact d’extraction texte auditée.

Type renvoyé:

Path

write_text_extraction_audit(payload, out_path)

Écrit l’artefact d’audit d’extraction texte.

Type renvoyé:

Path

text_extraction.text_extraction_markdown_writer

Écriture du fichier markdown d’extraction textuelle (source de vérité auditée).

get_canonical_text_extraction_md_path(project_root, bank_code, year, quarter)

Retourne le chemin canonique du .md d’extraction pour une période.

Le .md vit dans outputs/text_extractions/{bank}/{year}/{q}/text_extraction.md et est réutilisé par les runs suivants pour éviter de relancer Docling. Pour forcer une ré-extraction, supprimer ce fichier.

Type renvoyé:

Path

get_raw_docling_markdown_path(project_root, bank_code, year, quarter, role)

Retourne le chemin du markdown brut exporté directement par Docling.

Type renvoyé:

Path

get_text_extraction_markdown_path(out_dir, quarter_label)

Retourne le chemin du fichier markdown d’extraction pour un trimestre donné.

Type renvoyé:

Path

write_text_extraction_markdown(content, out_path)

Écrit le contenu markdown dans le fichier de sortie et retourne le chemin.

Type renvoyé:

Path
