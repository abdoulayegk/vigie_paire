vigilance.extract package

Submodules

vigilance.extract.exclusions module

Logique d’exclusion de pages basee sur des patterns regex configures en YAML.

vigilance.extract.exclusions.compile_exclusion_patterns(cfg)

Compile les patterns regex depuis le bloc de configuration des exclusions.

Paramètres:

cfg (dict) – Dictionnaire de configuration bancaire contenant cfg["exclusions"]["block_title_patterns"].

Type renvoyé:

list[Pattern]

Renvoie:

Patterns compiles (insensibles a la casse).

vigilance.extract.exclusions.get_skipped_pages(pdf_path, cfg, max_pages=None)

Retourne la liste triee des indices de pages (0-indexe) a ignorer.

Une page est ignoree lorsque le nombre de patterns d’exclusion distincts qui correspondent a son texte atteint ou depasse le seuil min_hits_to_skip configure.

Paramètres:

  • pdf_path (str) – Chemin du fichier PDF.

  • cfg (dict) – Dictionnaire de configuration bancaire avec bloc exclusions.

  • max_pages (int | None) – Si fourni, n’inspecte que les max_pages premieres pages.

Type renvoyé:

list[int]

Renvoie:

Indices de pages 0-indexes a ignorer, tries.

vigilance.extract.pdf_text module

Extraction de texte depuis des pages PDF via pdfplumber.

vigilance.extract.pdf_text.extract_page_text(pdf_path, page_index)

Extrait le contenu textuel d’une page PDF unique.

Paramètres:

  • pdf_path (str) – Chemin du fichier PDF.

  • page_index (int) – Index de page 0-indexe.

Type renvoyé:

str

Renvoie:

Texte extrait, ou "" si pdfplumber retourne None.

vigilance.extract.pdf_text.extract_pages_text(pdf_path, page_indices)

Extrait le texte de plusieurs pages PDF en un seul appel d’ouverture.

Paramètres:

  • pdf_path (str) – Chemin du fichier PDF.

  • page_indices (list[int]) – Indices de pages 0-indexes a extraire.

Type renvoyé:

dict[int, str]

Renvoie:

Dictionnaire {index_de_page: texte_extrait}.
