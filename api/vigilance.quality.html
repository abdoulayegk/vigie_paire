Qualité

Modules

quality.quality_gate

Porte de qualite stricte pour les sorties d’extraction basees sur le tables.json canonique.

evaluate_extraction_quality(tables, *, config=None, max_suspect_evidence=50)

Evalue la qualite d’extraction a partir des statuts d’extraction canoniques.

Paramètres:

  • tables (list[Any]) – Liste d’artefacts de tableau avec attribut extraction_status.

  • config (dict[str, Any] | None) – Surcharges de configuration optionnelles.

  • max_suspect_evidence (int) – Nombre maximal de preuves suspectes a collecter.

Type renvoyé:

dict[str, Any]

Renvoie:

Rapport de qualite d’extraction avec statut PASS/FAIL.

evaluate_quality(indicators_payload, footnotes_payload, *, config=None)

Evalue la qualite structurelle des indicateurs et footnotes extraits.

Paramètres:

  • indicators_payload (dict[str, Any]) – Payload projete des indicateurs.

  • footnotes_payload (dict[str, Any]) – Payload projete des footnotes.

  • config (dict[str, Any] | None) – Surcharges de configuration optionnelles.

Type renvoyé:

dict[str, Any]

Renvoie:

Rapport de qualite avec statut PASS/FAIL, scores par tableau et actions recommandees.

main(argv=None)

int

run_quality_gate(*, tables_path, out_dir, bank_code, run_id, config=None)

Execute les controles qualite et ecrit les fichiers de rapport et de statut.

Paramètres:

  • tables_path (Path) – Chemin du fichier tables.json canonique.

  • out_dir (Path) – Repertoire de sortie pour les rapports.

  • bank_code (str) – Code de la banque.

  • run_id (str) – Identifiant du run d’extraction.

  • config (dict[str, Any] | None) – Surcharges de configuration optionnelles.

Type renvoyé:

dict[str, Any]

Renvoie:

Dictionnaire de statut avec chemins des rapports generes.
