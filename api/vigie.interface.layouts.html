Mises en page de l’interface

Modules

interface.layouts.page_load

Page chargement d’une comparaison existante.

build_page_load(options)

Construit le layout de la page de chargement d’une analyse enregistree.

Paramètres:

options (list[dict]) – Liste de dictionnaires {label, value} pour le menu deroulant de selection des comparaisons sauvegardees.

Type renvoyé:

Div

Renvoie:

Composant html.Div contenant le formulaire de chargement.

interface.layouts.page_results

Page des resultats de comparaison avec design moderne et onglets par section.

build_analyst_kpi_card(title, value, delta_icon=None, color='light', helper_text=None)

Construit une carte KPI individuelle pour le panneau analyste.

Paramètres:

  • title (str) – Libelle affiche au-dessus de la valeur.

  • value (str | int) – Valeur principale du KPI (texte ou entier).

  • delta_icon (str | None) – Icone optionnelle de variation affichee sous la valeur.

  • color (str) – Classe de couleur Bootstrap pour le fond de la carte.

  • helper_text (str | None) – Texte d’aide optionnel affiche sous la valeur.

Type renvoyé:

Card

Renvoie:

Composant dbc.Card representant la carte KPI.

build_page_results()

Construit le layout principal de la page de resultats.

Inclut les KPI, le panneau de revue analyste et les statistiques de validation.

Type renvoyé:

Div

Renvoie:

Composant html.Div contenant l’ensemble de la page de resultats.

build_section_accordion_item(section_name, tables_with_changes, tables_added, tables_removed, item_id, current_quarter_label='Trimestre courant', previous_quarter_label='Trimestre précédent')

Construit un element d’accordeon pour l’onglet des changements par section.

Paramètres:

  • section_name (str) – Nom de la section affiche dans le titre de l’accordeon.

  • tables_with_changes (list) – Comparaisons de tableaux comportant des changements.

  • tables_added (list) – Tableaux presents uniquement dans le trimestre courant.

  • tables_removed (list) – Tableaux presents uniquement dans le trimestre precedent.

  • item_id (str) – Identifiant HTML de l’element d’accordeon.

  • current_quarter_label (str) – Libelle du trimestre courant, si disponible.

  • previous_quarter_label (str) – Libelle du trimestre precedent, si disponible.

Type renvoyé:

AccordionItem

Renvoie:

Composant dbc.AccordionItem representant la section.

interface.layouts.sidebar

Sidebar layout pour la configuration.

build_sidebar()

Construit la barre laterale de configuration de l’analyse.

La sidebar contient les champs de contexte analyste (nom, banque, annee, trimestre), le selecteur d’analyses enregistrees et les options avancees.

Type renvoyé:

Col

Renvoie:

Composant dbc.Col representant la barre laterale complete.
