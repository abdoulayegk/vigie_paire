build_vigie_extract(*, pdf_path, bank_code, quarter, year, language='fr', section_ranges, tables)

Construit le payload vigie_extract_v1 a partir des sorties d’extraction.

Paramètres:

  • pdf_path (str | Path) – Chemin du PDF source.

  • bank_code (str) – Code de la banque (ex. "cibc").

  • quarter (str) – Trimestre (ex. "t2-2025" ou "t2_2025").

  • year (int) – Annee fiscale.

  • language (str) – Code langue ISO (defaut "fr").

  • section_ranges (list[dict[str, Any]]) – Liste de dictionnaires avec cles "section", "start", "end" et optionnellement "evidence".

  • tables (list[Any]) – Liste d’objets ExtractedTable ou equivalents.

Type renvoyé:

VigieExtractPayload

Renvoie:

Payload complet VigieExtractPayload.
