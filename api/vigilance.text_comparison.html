Comparaison texte

Sous-package du pipeline texte canonique. Sérialise text_comparison.json, produit l’export Excel analyste et porte les helpers de justification utilisés pour rendre lisibles les sorties du triage AMF.

Modules

Type renvoyé:

build_text_triage_justification(change)

Retourne la justification AMF v2 ou un fallback structure pour Dash/Excel.

Les nouveaux artefacts doivent contenir genai_triage.nouvelle_idee_justification. Les anciens artefacts texte produits par gpt4o_triage peuvent avoir nouvelle_idee=True sans ce champ. Dans ce cas, on reformate les champs disponibles en note d’analyste structuree pour eviter un affichage vide.

Type renvoyé:

str

text_comparison.text_comparison_excel

Export des résultats de comparaison texte vers un classeur Excel analyste.

generate_text_comparison_excel(text_comparison, output_path=None)

Génère le classeur Excel analyste à partir de text_comparison.json.

Affiche tous les changements détectés hors unchanged, triés par nouvelle idée puis par priorité. Les dates pures, variations chiffrées et reformulations restent visibles pour décision analyste. L’analyste valide chaque ligne via la colonne Statut.

Paramètres:

  • text_comparison (dict[str, Any]) – Dictionnaire text_comparison.json complet.

  • output_path (str | Path | None) – Chemin de sortie .xlsx. Si None, retourne les bytes.

Type renvoyé:

Path | bytes

Renvoie:

Path du fichier créé, ou bytes si output_path est None.
